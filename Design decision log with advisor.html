Advisor: points to reconsider

The log stays in this browser only and is not sent anywhere. Do not enter names, client details or anything identifying. To keep a record, use Copy as table and paste it into a spreadsheet or document. Checkpoints come from the dissertation’s twelve-checkpoint model; a loop is counted whenever you return to the same checkpoint or an earlier one. The advisor uses fixed rules written from that model. It reads only what you logged, so its points are prompts for reflection, not verdicts, and the model itself is a proposal still to be tested.
